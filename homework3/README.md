## Задача 1: Ядро агрегатора такси

Вы пишете модуль расчета стоимости поездки для нового сервиса такси. Программа получает два аргумента при запуске: дальность поездки в километрах (целое число) и статус клиента в виде строки "true" (если есть VIP-подписка) или "false" (обычный клиент). Базовая стоимость одного километра пути составляет 50 рублей. В сервисе действует программа лояльности, благодаря которой каждый третий километр пути (3-й, 6-й, 9-й и так далее) является абсолютно бесплатным. Если у клиента есть VIP-подписка, к итоговой стоимости поездки применяется дополнительная скидка 20%. Однако руководство сервиса ввело строгое правило безопасности: чтобы не работать в убыток, VIP-скидка активна только в том случае, если общая дальность поездки составляет строго больше 5 километров. Для поездок на 5 километров и менее эта скидка полностью аннулируется.
Ваша задача — написать код, который с помощью цикла будет имитировать поездку километр за километром, рассчитывать стоимость и в конце выводить на экран итоговую цену поездки.

**Сценарии для самопроверки:**
```bash
  java TaxiCalc 7 false
```
```bash
  java TaxiCalc 7 true
```
```bash
  java TaxiCalc 4 true
```

## Задача 2: Симуляция Бариста-бота

Вы программируете умную кофемашину, в которую изначально залито 1000 мл воды и 500 мл молока, а запас кофе в зернах считается бесконечным. Программа получает два аргумента командной строки: количество заказанных чашек и тип напитка ("americano" или "latte"). На приготовление одной порции американо машина тратит 200 мл воды, а на одну порцию латте — 100 мл воды и 100 мл молока. Машина должна в цикле готовить напитки, уменьшая запасы в переменных, до тех пор, пока не выполнит весь заказ или пока не закончатся нужные ингредиенты (в этом случае цикл досрочно прерывается). При этом у кофемашины есть конструктивная особенность трубки подачи молока: после приготовления ровно четырех порций латте подряд капучинатор засоряется пеной. Машина аппаратно блокируется и не может выдать пятую и последующие порции латте, даже если баки с молоком и водой еще полны (на приготовление американо это правило никак не влияет).
Ваша задача — написать симуляцию работы кофемашины, которая по итогу выведет на экран фактическое количество приготовленных чашек, а также оставшийся объем воды и молока в баках.

**Сценарии для самопроверки:**
```bash
  java BaristaBot 4 americano
```
```bash
  java BaristaBot 3 latte
```
```bash
  java BaristaBot 6 latte
```
