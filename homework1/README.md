# Домашняя работа №1: Базовые операции, ввод данных и чтение логов

**Как это работает:**
Пока мы не изучали массивы глубоко, воспринимайте `args` как набор пронумерованных ячеек. Первая переданная строка попадает в ячейку `args[0]`, вторая — в `args[1]` и так далее.
*Пример запуска в терминале:* `java Main 15 20` (где `15` — это `args[0]`, а `20` — это `args[1]`).

**Важное правило:** Так как мы пока не умеем проверять, сколько именно аргументов ввел пользователь, **всегда передавайте ровно то количество аргументов, которое просит задача**. Иначе программа выбросит страшную ошибку `ArrayIndexOutOfBoundsException` (мы научимся с ней бороться на следующих парах). Избегайте кириллицу, терминал её не переваривает.

### Задача 1: "Жадный кассир"
**Важное отступление перед стартом:**
Аргументы командной строки args всегда передают данные в виде текста (тип String), даже если вы ввели цифры. Чтобы Java поняла, что с этим текстом нужно делать математические вычисления, текст нужно "перевести" в число.
Так как глубоко эту тему мы будем изучать позже, пока используйте готовую команду-помощник:
`int myNumber = Integer.parseInt(args[0]);` — она берет текст из нулевой ячейки и превращает его в полноценное число int.

Напишите программу, которая принимает на вход одну строку через `args[0]` — сумму сдачи в копейках (например, `854`).
Программа должна перевести эту сумму в рубли и копейки и вывести на экран.
*   **Условие:** Использовать только целочисленные типы данных (`int`) и операторы `/` (целочисленное деление) и `%` (остаток от деления). Дробные типы (`double`, `float`) использовать **запрещено**.
*   **Пример работы:**
    `java Cashier 854` -> `Ваша сдача: 8 руб. 54 коп.`

### Задача 4: "Сломанная машина времени"
Этот код должен брать год прыжка из `args[0]` и скорость из `args[1]`. Но он содержит 2 ошибки компиляции и 2 логические ошибки.

```java
public class TimeMachine {
    public static void main(String[] args) {
        int currentYear = 2026;
        int jumpYears = args[0]; 

        if (jumpYears > 0) {
            int destination = currentYear + jumpYears;
        } else {
            int destination = currentYear;
        }

        System.out.println("Вы прибыли в " + destination + " год!");

        int speed = Integer.parseInt(args[1]);
        int lightSpeed = 300000000;
        int energy = speed * lightSpeed; 
        
        System.out.println("Потрачено энергии: " + energy);
    }
}
```
*   **Задание:**
    * Запустите код с аргументами `10` и `15`.
    * Исправьте ошибку типизации при чтении из `args[0]`.
    * Исправьте ошибки области видимости переменных (scope) в блоке `if-else`.
    * Объясните, почему при скорости `15` результат энергии получается отрицательным. Как починить типы данных, чтобы ответ стал правильным?

### Задача 5: "Идеальное среднее арифметическое"
Код должен брать 4 числа из аргументов командной строки, складывать первые три и делить на четвертое.

```java
public class PerfectAverage {
    public static void main(String[] args) {
        System.out.printLn("Считаем результат...");

        int a = Integer.parseInt(args[0]);
        int b = Integer.parseInt(args[1]);
        int c = Integer.parseInt(args[2]);
        int divider = Integer.parseInt(args[3]);

        int sum = a + b + c;
        int average = sum / divider;

        System.out.println("Результат: " + average + 10);
    }
}
```
*   **Задание:**
    1. Найдите и исправьте синтаксическую опечатку (ошибка компиляции).
    2. Запустите программу: `java PerfectAverage 10 20 30 0`. Программа упадет с `ArithmeticException`. Добавьте условие `if-else`: если `divider` равен 0, выводите "Делить на ноль нельзя!" и не выполняйте расчет.
    3. Запустите программу: `java PerfectAverage 10 20 30 2`. Среднее должно быть `30`. Но последняя строка выводит `Результат: 3010`. Почему так работает оператор `+` со строками? Исправьте вывод, чтобы вывелось правильное число `40` (то есть среднее + 10).
