# Домашняя работа №2: Работа с массивами

Для заданий со 2 по 10 запрещено использовать готовые методы из класса `java.util.Arrays`. Всю логику обхода и обработки массивов вы должны написать самостоятельно.

### Code Review
Вам достался фрагмент кода от предыдущего разработчика. Он пытался написать логику проверки резервных копий, заполнения коэффициентов и подсчета сумм. Проблема в том, что программа не компилируется, а если обойти ошибки компиляции, она падает с ошибками во время выполнения.

Ваша задача найти каждую из них, объяснить причину возникновения и исправить код так, чтобы программа успешно отработала.

```java
public class ArrayFixer {

    public static void main(String[] args) {
        startApp();
    }

    public ArrayFixer() {
        System.out.println("Инициализация системы...");
    }

    public void startApp() {
        int[] currentData = {10, 20, 30};
        int[] backupData = {10, 20, 30};

        System.out.println("Проверка резервной копии:");
        if (currentData == backupData) {
            System.out.println("Данные совпадают. Резервная копия актуальна.");
        } else {
            System.out.println("Внимание! Данные рассинхронизированы.");
        }

        int[] multipliers = new int(5);
        System.out.println("Подготовка коэффициентов завершена.");

        System.out.println("Умножение текущих данных...");
        for (int i = 0; i <= currentData.length; i++) {
            currentData[i] = currentData[i] * 2;
        }

        int totalSum;
        for (int i = 0; i < currentData.length; i++) {
            totalSum = totalSum + currentData[i];
        }
        System.out.println("Общая сумма после умножения: " + totalSum);

        System.out.println("Размер обработанного массива: " + currentData.length());
    }
}
```
### Задание 2. Выявление наихудших показателей
Отделу аналитики требуется инструмент для выявления просадок в статистике. Разработайте метод, принимающий набор числовых данных и возвращающий самое маленькое значение из присутствующих. Если на вход поступят данные с показателями 7, -2, 9, 0, ожидается, что метод проанализирует их и вернет число -2.
### Задание 3. Проверка логов безопасности
Службе безопасности необходимо уметь быстро проверять, фигурирует ли определенный идентификатор в базе логов. Напишите метод, который примет массив данных и целевое искомое число. В качестве ответа алгоритм должен выдать логическое значение true, если число было найдено, или false, если такого значения в системе нет.
### Задание 4. Поиск позиции элемента
Иногда просто знать о наличии элемента в логах недостаточно, требуется выяснить его точную позицию. Реализуйте алгоритм поиска индекса, который принимает массив и искомое число. Метод должен вернуть порядковый номер (индекс) ячейки, где хранится целевое число. В случае, если данные отсутствуют, метод должен выдать -1, выступая в роли сигнала о том, что элемент не найден.
### Задание 5. Подсчет успешных операций
Финансовый отдел запросил функцию фильтрации успешных сделок. Вам нужно разработать метод, который проанализирует переданный массив и вернет точное количество строго положительных чисел. Например, из набора {-1, 5, 0, 9, -3} метод должен вернуть 2, так как подходящими являются только пятерка и девятка.
### Задание 6. Расчет бонусной суммы
Для расчета премий, начисляемых только за четные операции, бухгалтерии необходим особый алгоритм суммирования. Напишите метод, который пройдет по всему переданному массиву, отфильтрует только те числа, которые делятся на два без остатка, сложит их между собой и вернет итоговую накопленную сумму.
### Задание 7. Безопасное резервирование данных
Прежде чем применять к данным опасные трансформации, системе необходим механизм создания независимых резервных копий. Во избежание перезаписи оригиналов реализуйте метод клонирования. Этот алгоритм должен самостоятельно создать в памяти абсолютно новую структуру такого же размера, как и переданная, поочередно скопировать туда все элементы без исключения и вернуть этот новый массив.
### Задание 8. Ротация очереди
Для задач логистики реализуйте механизм циклического сдвига очереди. Ваш метод должен модифицировать переданный массив, сдвигая все его элементы на одну позицию вправо. Важнейшим условием является то, что самый последний элемент не должен быть потерян — он обязан переместиться на освободившееся первое место. Массив {1, 2, 3, 4} после вызова метода должен превратиться в {4, 1, 2, 3}.
### Задание 9. Сравнение периодов
Отдел планирования попросил добавить функцию инверсии полугодий. Для этого вам необходимо написать алгоритм, который ровно пополам разделит переданный массив и поменяет его первую половину со второй. Учитывая, что на вход поступают четные объемы данных, массив из шести элементов {1, 2, 3, 4, 5, 6} после вызова метода должен изменить свое внутреннее состояние и выглядеть как {4, 5, 6, 1, 2, 3}.
### Задание 10. Безопасное удаление записи
В завершение разработки нужно реализовать функционал удаления записи по ее индексу. Поскольку размер стандартного массива в Java изменить невозможно, ваша логика должна создать новый массив, который будет ровно на одну ячейку меньше старого. В него необходимо аккуратно перенести все исходные данные, пропустив лишь тот элемент, что находился по переданному индексу, после чего вернуть новую уменьшенную структуру.
